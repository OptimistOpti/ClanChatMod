# ClanChat backend

Отдельный WebSocket-сервис для клиентского мода ClanChat. Не является Minecraft-сервером
и не требует доступа к его файлам — ставится куда угодно, где есть Node.js (например,
Wispbyte).

## Протокол

Один WebSocket-коннект на игрока. Все сообщения — JSON-текстовые фреймы вида:

```json
{"action": "SEND_MESSAGE", "data": {"channel": "CLAN", "content": "привет"}}
```

Полный список действий — в `../src/main/java/com/optimistopti/clanchat/network/ClanAction.java`
на стороне мода (протокол общий, оба конца должны совпадать).

Первое сообщение от клиента после подключения — всегда `IDENTIFY` с `{name, uuid}`.
**Бэкенд доверяет нику от клиента без криптографической проверки** — это осознанный
компромисс для серверов без обязательной лицензии (offline-mode), где нет возможности
свериться с сессией Mojang. Для приватного круга друзей это нормально; если понадобится
защита от подделки ника — можно добавить сверку через `sessionserver.mojang.com`
(Mojang joinServer/hasJoined) для тех, кто играет в лицензионном режиме.

## Локальный запуск

```
cd backend
npm install
npm start
```

По умолчанию слушает `ws://0.0.0.0:8080`. Порт берётся из переменной окружения `PORT`
(или `CLANCHAT_PORT`).

Данные (кланы) пишутся в `data/clans.json` — простой JSON-файл, никакой БД не требуется.
Путь можно переопределить переменной окружения `CLANCHAT_DATA_DIR`.

## Деплой на Wispbyte

Wispbyte — Pterodactyl-подобная панель: сервер создаётся из готового Docker-образа
(Node.js, Bun, Python, Java и т.д.), после чего можно загрузить файлы (через файловый
менеджер панели или git) и настроить команду запуска и переменные окружения.

Шаги (сверяйся с актуальным интерфейсом панели — он мог измениться):

1. **Create Server** → выбери образ **Node.js**.
2. Залей содержимое папки `backend/` в корень сервера (файловый менеджер панели
   поддерживает загрузку архивом/по одному файлу; либо `git clone` этого репозитория,
   если на сервере есть доступ к консоли с git).
3. В настройках сервера задай **Startup Command**: `npm install && npm start`
   (или раздели на отдельный шаг установки, если панель поддерживает pre-install hook).
4. В **Environment Variables** пропиши `PORT` (Wispbyte обычно сам прокидывает нужный
   порт через эту переменную — сервер уже её читает).
5. Запусти сервер, в логах должно появиться `[ClanChat backend] слушаю ws://0.0.0.0:<port>`.
6. В моде (Настройки → ClanChat) укажи адрес: `ws://<хост-от-wispbyte>:<порт>`.
   Если Wispbyte выдаёт домен с HTTPS/прокси спереди — понадобится `wss://` и настройка
   проксирования WebSocket на этом уровне (обычные reverse-proxy типа nginx/Caddy это
   умеют из коробки, просто не забудь про `Upgrade`/`Connection` заголовки).

## Известные ограничения (см. также корневой README, раздел TODO)

- Идентификация без крипто-проверки (см. выше).
- История чата — только в памяти процесса, обнуляется при рестарте.
- Один процесс, без кластеризации — для круга друзей более чем достаточно, но не
  рассчитано на сотни одновременных подключений.
