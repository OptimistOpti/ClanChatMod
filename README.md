# ClanChat

Полноценная система кланов для Fabric-клиента/сервера Minecraft **26.1.2** с чатом в
стиле Discord/Telegram: роли, инвайты, права, и вложения к сообщениям (координаты,
инвентарь, эндер-сундук, предмет в руке, статус здоровья).

Открывается по умолчанию клавишей **C** (переназначается в Настройки → Управление →
ClanChat, либо через экран настроек мода в ModMenu).

## Возможности

- **Кланы**: создание, роспуск, инвайты, кик, роли (Лидер/Офицер/Участник) с
  настраиваемыми правами (`ClanPermission`), передача лидерства.
- **Чат**: каналы Клан / Офицеры / Личные сообщения / Системные уведомления.
- **Вложения к сообщению**: координаты (можно кликнуть кнопку "Коорд." — прикрепится
  текущая позиция), предмет в руке, весь инвентарь, эндер-сундук, статус здоровья
  (авто-флаг "нужна помощь" при HP < 30%).
- **Fallback-команды** `/clan create|invite|accept|decline|leave|disband|kick|promote|demote|info`
  на случай, если GUI недоступен или нужна отладка с консоли.
- Персистентность кланов на диске (`<world>/clanchat/clans/<uuid>.json`).

## Стек

- Minecraft 26.1.2, Fabric Loader 0.19.3, Fabric API 0.155.2+26.1.2, Java 25.
- Официальные маппинги Mojang (в 26.x они используются "из коробки", Yarn для этой
  версии не подключается).
- Опциональная интеграция с [ModMenu](https://modrinth.com/mod/modmenu) для экрана
  настроек (мод работает и без ModMenu — см. `"suggests"` в `fabric.mod.json`).

## Сборка

```
./gradlew build
```

Готовый джарник — в `build.libs/`. Сборка проверена в CI (GitHub Actions, см. `.github/workflows/build.yml`) и **проходит зелёным**.

## Что было исправлено при первой реальной сборке

Изначальный код был написан без доступа к Maven-репозиториям Mojang/Fabric, поэтому
несколько мест пришлось поправить по фидбеку CI (это нормальная часть работы с версией,
где мэппинги совсем свежие):

- `modImplementation` → `implementation` (в Fabric Loom 1.17.x, с официальными
  Mojang-мэппингами без Yarn-ремаппинга, отдельных mod-конфигураций больше нет).
- `ServerPlayer#server` — приватное поле; `MinecraftServer` теперь кэшируется в
  `ClanChatMod` при старте сервера (`ClanChatMod.getServer()`).
- `.getGameProfile().getName()` → `.getName().getString()`.
- `Minecraft#setScreen(...)` — вызывается напрямую, без несуществующей обёртки `.gui`.
- `Player#displayClientMessage(...)` → `Player#sendSystemMessage(...)` на клиенте.
- `ResourceKey#location()` → `ResourceKey#identifier()` (переименован вслед за
  `ResourceLocation` → `Identifier`).
- Прямой доступ к приватному полю `Inventory#items` заменён на
  `getContainerSize()`/`getItem(i)`.
